# Nullus

**Kubernetes 위에 검증된 DevSecOps 스택을 — 클릭 몇 번으로.**

Nullus는 DevOps 엔지니어가 검증된 CI/CD 도구 조합(Golden Path)을 선택하고, 웹 UI에서 노코드로 설정한 뒤 한 번의 Deploy로 Kubernetes 클러스터에 전체 DevSecOps 스택을 자동 설치하는 오픈소스 플랫폼입니다. "클러스터 준비 → 스택 선택/설치 → 배포 관측"을 하나의 일관된 경험으로 제공합니다.

- 🧭 **Golden Path 템플릿** — GitLab·Argo CD·Harbor·Prometheus 등 검증된 조합만 제공, 버전 호환성 보장
- 🖱️ **노코드 설치** — 5단계 마법사, 실시간 진행률·로그 추적
- 📊 **통합 관측** — 스택 상태·이력·모니터링·알림을 한 화면에서
- 🔐 **SSO/RBAC** — Keycloak OIDC 기반 단일 로그인과 3단계 역할 체계
